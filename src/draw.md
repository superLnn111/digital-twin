# 风机数字孪生监测平台 — 高信息密度科研绘图方案

---

## 一、制图工具与风格总则

### 1.1 核心原则：PowerPoint 原生绘制 + 真实数据嵌入

**不推荐外部工具导出图片再贴入PPT。** 参考周老师模板图的做法：所有架构框、连接线、标注文字均用PPT原生形状直接构建，同时将真实的数据图表（训练曲线、混淆矩阵、t-SNE图、传感器截图等）**嵌入画布里混排**。这样做的好处：

| 优势 | 说明 |
|------|------|
| **矢量无损** | PPT原生形状无限缩放不模糊，投影/印刷均清晰 |
| **信息密度** | 形状 + 文字 + 嵌入数据图可任意叠放，一张幻灯片容纳多层信息 |
| **可编辑** | 任何时候都能修改颜色、位置、文字，不用回到外部工具重绘 |
| **风格统一** | 所有图共用一套配色和形状样式， racecondition |

### 1.2 推荐工作流

```
① 在PPT中画好所有架构框（矩形/圆角矩形/立方体）+ 连接线（肘形箭头）
       ↓
② 从Python/前端截取真实数据图（曲线/矩阵/截图），裁剪后嵌入到PPT画布对应位置
       ↓
③ 加文字标注（模块名、关键参数、分析结论）
       ↓
④ 统一调色、对齐、加阴影/发光效果
       ↓
⑤ 选中所有元素 → Ctrl+G 编组 → 命名 → 完成
```

### 1.3 配色方案（深色科研主题）

```
画布背景:      #020617 (深空蓝黑)
卡片/模块底色:  #0d1229 (深蓝灰，带30%透明度边框)
主标题色:      #06b6d4 (科技青 Cyan-500)
强调色:        #ff3333 (故障红 Red-500)
数据流线:      #3b82f6 (数据蓝 Blue-500)
成功色:        #10b981 (健康绿 Emerald-500)
辅助色:        #8b5cf6 (紫色 Violet-500)
警告色:        #f59e0b (警告橙 Amber-500)
正文文字:      #e2e8f0 (浅灰白 Slate-200)
次要文字:      #94a3b8 (灰 Slate-400)
模块渐变:      深色→浅色 线性渐变（如 #0d1229 → #1e293b）
```

### 1.4 通用PPT制图规范

- **字体**：全部使用 **微软雅黑 / Arial**（中文雅黑，英文Arial），标题加粗14pt，正文10pt，模块名加粗12pt
- **模块框**：使用「插入→形状→圆角矩形」，圆角弧度约5-8pt，填充深色底+1pt浅色描边
- **连接线**：使用「插入→形状→肘形箭头」或「曲线箭头」，线宽1.5-2pt，颜色使用数据流蓝 `#3b82f6`
- **箭头端点**：统一使用三角形实心箭头，起点圆形、终点箭头
- **虚线**：表示异步/无线链路，线宽1pt，间距3pt
- **阴影**：使用「形状格式→阴影→外部居中偏移」，透明度80%、模糊6pt、距离3pt，营造发光科技感
- **发光**：对关键模块（如DiagnosisProvider、3D风机）使用「形状格式→发光」效果，颜色=模块主题色
- **嵌入图片**：粘贴数据图后，右键→「设置图片格式」→加1pt边框（`#334155`）+ 外部阴影
- **图层规范**：背景层 → 架构框层 → 连接线层 → 嵌入图片层 → 文字标注层

## 四、PPT绘图快捷技巧

### 4.1 批量操作
- 用 **Ctrl+Shift+拖动** 快速复制形状并保持对齐
- 用「开始→排列→对齐」的「横向分布」和「纵向分布」快速等距排列
- 用「格式刷」快速统一形状样式

### 4.2 连接线技巧
- 连接线会自动吸附到形状边缘的连接点，拖动红点可调整连接位置
- 肘形连接线的折弯位置可通过拖动黄色菱形控制点调整

### 4.3 图层管理
- 用「开始→排列→选择窗格」管理图层顺序
- 重命名每个形状（在「选择窗格」中双击名称），便于后续查找

### 4.4 数值精确控制
- 右键形状→「大小和位置」→ 精确设置 X/Y/W/H 数值
- 按住Alt键拖动形状可临时关闭网格吸附

### 4.5 截图嵌入规范
- 截图先裁剪掉无关区域，统一分辨率（建议宽度 600-800px）
- 嵌入后添加1pt `#334155` 描边 + 外部偏移阴影
